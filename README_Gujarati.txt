RONAK WISH MAKER — WEBSITE FILES
Developer: Ronak Manani

આ ZIP માં:
1. index.html
2. style.css
3. app.js

સ્થાપન:
1. GitHub repository માં હાલની ત્રણ ફાઇલોનો backup લો.
2. આ ZIP Extract કરો.
3. Extract કરેલી ત્રણેય ફાઇલો repository ના root folder માં મૂકો.
4. GitHub માં જૂની ફાઇલો replace કરીને Commit changes કરો.
5. Website ખોલીને mobile માં પણ ટેસ્ટ કરો. જૂની cache દેખાય તો browser refresh કરો.

હાલ ઉપલબ્ધ:
- Royal Gold આધારિત responsive design અને 4 wish themes
- 50 મુખ્ય Hindu festival options અને festival search
- Custom festival add
- Gujarati / English toggle
- Create, save, edit, delete અને wish link copy
- Audio, video અને background image upload (મર્યાદા: 2 MB / 8 MB / 4 MB)
- Emoji reactions
- Browser આધારિત visitor activity નો અંદાજ
- Developer credit: Ronak Manani

મહત્વની મર્યાદાઓ:
- આ build માં Firebase અથવા server backend જોડાયેલું નથી.
- Admin button હાલમાં password protected નથી; તેથી Admin Panel ને secure/owner-only ગણશો નહીં.
- Wishes, reactions, custom festivals અને visitor activity એ જ browser/device ના Local Storage માં રહે છે.
- બીજા મોબાઇલ પર wish link ખોલવાથી wish data આપમેળે નહીં મળે.
- Visitor tracking વાંચનનો પુરાવો નથી; તે browser visibility/scroll પરથી અંદાજ આપે છે.
- મોટા media files અથવા browser storage limit ને કારણે save નિષ્ફળ થઈ શકે છે.
- કોઈ software માટે zero bug/zero lag ની ખાતરી આપી શકાતી નથી. Publish કરતાં પહેલાં વાસ્તવિક mobile testing જરૂરી છે.

આ ZIP હાલની અપલોડ કરેલી ફાઇલો પર આધારિત છે. Secure Admin Login અને multi-device sharing માટે Firebase/backend configuration અને security rules અલગથી કરવાના રહેશે.
